# Platform service iconography

`play-games-white.png` is the unmodified Google Play Games controller badge from Google's official Play Games Services branding resources, downloaded 2026-09-05.

Source: https://developer.android.com/static/images/games/pgs/branding/ic_play_games_badge_white.png
Guidelines: https://developer.android.com/games/pgs/branding

Used only on the Android entry point to the native Play Games achievement list. This is a provider logo, not game achievement artwork.
