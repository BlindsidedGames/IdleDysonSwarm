# French localization notes

The `fr` catalog uses neutral French suitable for France. Interface actions use the infinitive where they label controls and the polite second person where the game addresses the player.

## Native-review flags

- Review the Avocato/avocado and Avotation wordplay; the catalog keeps the coined proper names while translating the surrounding jokes.
- Review cultural references and deliberately absurd prose in skill descriptions, especially *Idle Electric Sheep*, *Parallel Processing*, the *Shoulders* series, *Terra Eculeo*, and *One Minute Plan*.
- Confirm whether canonical mega-structure names should remain English for brand continuity; this draft localizes them as Cerveau matriochka, Planète de Birch, and Cerveau galactique.
- Confirm capitalization of progression resources in final UI context. The draft capitalizes named currencies and systems, while ordinary descriptive uses may be lowercase.
- Inspect compact mobile labels and skill-node titles for expansion; French is frequently longer than the English source.
