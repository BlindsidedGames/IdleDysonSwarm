# Unity development snapshot reference

This directory preserves documentation from the final Unity development tree
removed from `main` on 2026-08-21. It describes an **unreleased post-3.0.328
development snapshot**, not the public 3.0.328 binary.

The complete source tree remains available on branch
`archive/unity-development-handoff-2026-08-21` and annotated tag
`unity-dev-handoff-2026-08-21`, both at commit
`cc21ca0ee632ac950a69ba14842b3fd7b5f7976c`. Paths beginning with `Assets/`,
`Documentation/`, `Packages/`, or `ProjectSettings/` refer to that archive.

These files are historical evidence. Current implementation and product
contracts live elsewhere under `Web/docs/`.
