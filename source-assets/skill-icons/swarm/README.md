# Swarm and Fragment augments

Follow [the artwork workflow](../../../docs/skill-icon-artwork.md).
Hexagons, purchase cards, Fragment pieces, loop arrows and the crossed-eye Bot
reuse alpha traces of the original 2084px Super Swarm, Investment, Fragment
Assembly, Repeatable Research and Stellar Sacrifices masters at
`cc21ca0ee632ac950a69ba14842b3fd7b5f7976c`. The live Bot reuses the original
navigation silhouette already preserved in Manual Labour's editable SVG.

Each SVG uses a 256-unit canvas, white fills and transparent even-odd cutouts.
Export with the repository's Sharp at density 288, resize to 256×256 and write
lossless WebP to `src/ui/assets/skill-icons/` using the matching filename.
No tracing dependency is added to the game.
